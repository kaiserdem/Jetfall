# GameSK — Aviator Space Combat

## Опис додатку

GameSK — iOS-гра з 3D-космічним бойовиком у авіаційній стилістиці.
Гравець знищує астероїди в 100 секторах, стежить за паливом і заробляє кредити на нові літаки.
UIKit + SceneKit, темна cockpit-тема, прогрес зберігається локально.

Основні екрани: **Menu**, **Missions**, **Hangar Shop**, **Game**.


## Екрани додатку

### 1) Menu
- Статус пілота: наступний сектор, best run, кредити, поточний літак.
- 3D-превʼю літака на анімованому зоряному фоні.
- **Continue Mission** — вибір місії.
- **Hangar Shop** — магазин літаків.

### 2) Missions
- Карусель із 100 секторами (swipe або ‹ ›).
- Картки: Locked / Ready / Clear / Open.
- Прогрес кампанії та баланс кредитів.
- **Launch Mission** — старт обраного відкритого сектора.
- Складність зростає: більше астероїдів, швидші вороги, менше палива.

### 3) Hangar Shop
- 10 літаків у каруселі з 3D-превʼю.
- Перший літак — безкоштовний, решта — за пройдені сектори + кредити.
- Дії: **Buy** / **Equip** / Locked.
- Некуплені літаки показуються з blur.

### 4) Game
- 3D-бій: D-Pad для руху, кнопка вогню.
- HUD: рівень, знищені цілі, score, паливо.
- **Pause** — продовжити, магазин або вихід.
- Результат місії: перемога, поразка (паливо/зіткнення) або фінал кампанії.
- Очки за вбивства + fuel bonus → кредити в ангар.
